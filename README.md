# Business & Money Tools Factory

Arabic-first, bilingual-ready utility site.

## Flagship tool

**Ecommerce Profit & Break-even Calculator**

### MVP inputs
- Selling Price
- Product Cost
- Shipping
- Payment / Platform Fee
- Discount
- CAC / Ad Spend per Order
- Returns Rate

### MVP outputs
- Net Profit / Order
- Net Margin
- Maximum CAC
- Break-even ROAS
- Break-even Selling Price

## Local development

npm install
npm run dev
